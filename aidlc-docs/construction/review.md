## 最初に確認してほしいこと

Windowsのブラウザで <http://127.0.0.1:4173/> を開き、**ZIPを開く**から、Riot Gamesから受け取った元のZIPを解凍せずに選ぶ。ZIPは公開用フォルダに移さず、端末に保存してある場所から直接選ぶ。

- ホームに進み、記録があるカテゴリで明細を開けるか。
- ZIPを読み込めなかった場合は、画面に出たエラー文だけを共有する。一部だけ表示されない場合は、該当カテゴリ名と「未収録」か「読み込めませんでした」かを共有する。**ZIP・Riot ID・生JSON・明細は共有しなくてよい。**

実ZIPを用意できないときは [架空の正常ZIP](../../samples/valorant-sample.zip) で同じ操作を確認できる。ただしその結果はRiotの実データ形式の確認にはならない。

## 実機での受け入れ確認（非公開で配信できる環境を用意したあと）

| 確認 | 期待する動作 |
| --- | --- |
| iPhone Safari・Android Chromeでファイル選択 | 「ファイル」や「ダウンロード」から元のZIPを選び、ホームと各詳細を開ける。 |
| 大きめの実ZIP | 読み込み中も取り消せる。20秒以上かかる・ブラウザが終了する場合は、端末とブラウザ・概算時間やZIPのサイズだけを控える。 |
| ページ表示後に機内モード | 同じページを再読込せず、端末にダウンロード済みのZIPを選び、結果が出る。 |
| エラー・消去 | ZIPを選び直しても重複しない。失敗時は前の表示が残る。消去とページ再読み込みで表示が消える。 |
| スマホの導線 | ホーム、プレー記録、その他で横にはみ出さず、明細や一番下のボタンまで操作できる。 |

`127.0.0.1` は開いた端末自身を指すため、WindowsのプレビューURLはスマホから直接開けない。スマホ確認用の配信ルートは別途決める。インターネットに無断公開しない。

## 実施済み

- Node.js 22：JSTの月境界、勝率、通報の0件／データなし、通貨、ZIP構造・CRC・展開上限、Workerの部分取込を架空データで検証。
- Windows Chrome：360・390・768・1280pxで主要画面、ナビ、絞り込み、明細、消去を検証。ファイル入力から実際の架空ZIPを指定し、同じZIPの再取込、破損・対象なしで前表示を維持、取り消しを確認。
- Chromeをオフラインに切り替えたあと、別ZIPとドラッグ＆ドロップを処理できることを確認。初期取得のあとにHTTPリクエストが追加されないこともテストで確認。
- 提供された開示ZIP 1件をChromeで確認。対戦のモード・勝敗・コンペ勝率、通報、課金、ストアの通貨別消費量と明細が表示された。ZIPに受けた通報の集計がない場合は「データなし」と表示する。実データは作業フォルダには置いていない。
- モバイル実機は未確認。公開・登録はしていない。
