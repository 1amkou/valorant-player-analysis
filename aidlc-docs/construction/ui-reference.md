# 参照画像に合わせる画面構成・トークン

添付画像の左をデスクトップ、右をスマホの基準とし、端末の外枠は実装しない。既存の静的HTML・CSS・ESモジュール・SVG描画、端末内Workerを維持する。

| 領域 | PC | 390px付近のスマホ |
|---|---|---|
| App Shell | 白の固定サイドバー約210px、白いヘッダーバーにファイルを開く導線 | 白いヘッダーバーにロゴとメニュー。ホーム／プレー記録／その他を下部に固定 |
| プレーヤー概要 | 円形アバター・Riot ID・最終プレーと3枚の数値カードを1行に | プロフィールの次に等幅3枚の数値カード |
| ホーム | 約2:1でプレー記録とモード内訳、下2段は2等分 | プレー記録とモード内訳を1枚にまとめ、通報・課金・ストア・最近の試合を縦に並べる |
| コンポーネント | App Shell／プロフィール／KPI／共通カード／グラフ・凡例／明細／取込状態／使い方 | 同じコンポーネントをCSSで独立した配置に調整 |

CSSトークンは背景 `#F6F8FC`、カードとサイドバー `#FFFFFF`、境界 `#E8EDF5`、グリッド `#E6ECF5`、見出し `#202737`、本文 `#354257`、補助 `#8490A5`、ブルー `#4779C9`、淡いブルー `#B6CEF5`、ラベンダー `#8586DF`、アクティブ背景 `#EDF3FD`。カードは14–16pxの角丸とごく弱い影を使い、数値は等幅数字。主要文字は日本語とし、画像にあるブランドサブタイトルだけは英語表記。収録されていない数字や日時は作らず、ボイスチャットは不明な形式を推測しない。

視覚確認はWindows Chromeで1440×900と390×844。参照画像に対し先に全体配置と画面密度、次にチャート、色・余白・文字階層を確認した。初回の撮影後、月ラベルの重複、通報バー、スマホの凡例、PCの下段の高さを調整し、再撮影した。[PC 1440×900](visual/desktop-1440x900.png) · [スマホ 390×844](visual/mobile-390x844.png)。スクリーンショットはサンプル表示のみ。

ZIP・JSONは端末内のWorkerで処理する。Riot IDは開示ファイルに確認済みの2項目がある場合だけ表示する。画像ではマップのサムネイルがあるが、実ZIPからマップを特定できないためアイコンを使用。ボイスチャットの空・欠落・未対応を区別し、未確認の文字起こしは表示しない。課金のミニグラフは複数通貨を混ぜず、優先通貨1種類。ストアの棒グラフは取引件数で、タイムゾーンが不明な明細は開示ファイルに記載された月を使う。

プロフィール画像は [Valorant-API](https://valorant-api.com/) から取得したゲーム公開素材のジェット（表示用イメージ、プレイヤーが使ったエージェントを表さない）。Inter・Noto Sans JPの配布ライセンスとLucideのライセンスを配信物に同梱し、描画に外部CDNを使わない。
