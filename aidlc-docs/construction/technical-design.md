# 技術設計｜VALORANTプレイヤー分析ダッシュボード

[要件定義](../inception/requirements.md) · [承認済みの画面設計](../inception/screen-design.md)

## 配信・処理の境界

- `site/` のみを配信する静的サイト。相対URLを使い、GitHub Pagesの `/リポジトリ名/` の下でも動かす。開発時・レビュー時はHTTPで配信する（HTMLの直接起動は旧ワイヤーフレームのみ）。外部API・CDN・分析・広告・外部ストレージへの接続を使わない。
- 初期ページの取得時にUIとWorkerのコードを読み込む。Workerはビルド時に依存を一つのファイルにまとめ、UIは取得済みのコードからBlob URLでWorkerを起動する。再選択・中止・消去でWorkerを終了し、必要なときは同じコードから新しいWorkerを作る。初期資材の取得後はZIPの選択から表示まで追加の通信を必要としない。オフラインでのページ再取得は対象外。
- UIが持つのは正規化済みのデータ。仮の読み込み中は既存表示を維持し、成功時だけ置き換える。ZIPやファイル名をURL・ログに書かず、選択済みファイルをキューに溜めない。読み込み後の正規化済みデータは、再読み込み時の復元に備えて端末のブラウザ内（IndexedDB）にだけ保存する。元のZIP・JSONや未加工の個人データは保存しない。「表示データを消去」で保存分も削除する。

## 取込パイプライン

1. Workerは中央ディレクトリを調べ、`valorant/` 直下の対戦履歴、通報集計、課金、ストア取引の4JSONだけを選択して展開する。音声文字起こしと他タイトル・アカウント情報は読まない。展開結果をファイルシステムに書き出さない。
2. ZIP構造、圧縮形式、宣言サイズ、展開中の実サイズ、対象のチェックサムを検証する。初期の上限値は入力64 MiB、中央ディレクトリ4 MiB・4,096エントリ、対象1件16 MiB・全件32 MiB。スマホ実機測定前の暫定値。Deflateには `DecompressionStream('deflate-raw')` を使う。非対応ブラウザには別のブラウザを案内し、外部ライブラリは取りに行かない。ZIP64、分割・暗号化など対応できない形式はエラーとして扱う。
3. 厳密なUTF-8でデコードし、JSON構造を検証・正規化する。正常な空配列は空、対象ファイル未収録は欠落、存在するが読めないものは解析不可。部分的に読めるときは、その範囲を表示する。認識できない構造を0件とみなさない。
4. UIは正規化したデータを表示・集計する。読み込みと展開をUIスレッドで行わず、詳細一覧は段階表示でDOMサイズを抑える。

## データ上の判断

- 日時は端末のタイムゾーンで解釈しない。明示されたオフセットを使うか、オフセット省略時は `_utc` 名の項目だけをUTCとして扱い、日本時間（JST）で表示・月集計する。ストアの `purchase_date` にはオフセットなしの時刻も入るため、時刻を変換せず「タイムゾーン不明」を付けて明細に表示する。その他の解釈できない日時は「未記録」とし、月別集計に含めない。
- 開示ZIPの対戦履歴は `game_mode` が記録の種類（マッチメイキング・射撃場等）、`game_type` がマッチメイキング内のモード、`game_outcome` が勝敗。対戦数・試合時間・勝率は初期状態でマッチメイキングを対象とする。勝率はコンペの勝利÷勝敗が判明している件数。引き分け・不明は分母外。試合時間は開始・終了の差から算出し、欠けている試合は0分として足さない。
- 通報は方向別。既知コードは日本語、未知コードは元の表記。`null` と、空の理由集計による0件を区別する。通報は対戦の期間フィルターに連動しない。
- 決済は `real_currency_paid_x100` を100で割って表示し、異なる通貨を足さない。ストアは `spent_currency_name` と `spent_currency_amount` を使い、消費量が未記録の明細も残す。数値がある明細をゲーム内通貨別に集計する。

## 検証と制約

提供された開示ZIP 1件を作業フォルダにコピーせずローカルで確認し、対戦・通報・課金・ストア取引の表示をChromeで検証した。このZIPにない形式や機種での動作は未確認。回帰テストには同じフィールド構造の架空データを使う。ZIP・画面の個人情報・生JSONをリポジトリやチャットに残す必要はない。

GitHub Pagesへの配信とRiot Developer Portal登録は、ローカル受け入れ後に別工程で進める。リポジトリ・サイト名は公開前に確認する。
